## 🧩 About

**War Thunder GUI** is a comprehensive overlay for War Thunder featuring vehicle info, hit markers, damage log, config presets, and a clean customizable interface.

Based on popular overlays like **OpenHack**, **Eclipse Menu**, and **QOLMod**.

## ✨ Features

### 🎮 Core Overlay
- Vehicle Info — display speed, altitude, and heading
- Hit Markers — visual feedback for hits and kills
- Damage Log — detailed damage dealt and received
- Config Presets — save and load overlay profiles

### 🎨 Interface & Customization
- Customizable HUD — move, resize, and style elements
- Color Themes — dark, light, and custom palettes
- Font Selection — choose from multiple fonts

### 🏋️ Utility & Training
- Enhanced Crosshair — customizable crosshair overlays
- Config Editor — edit settings in real time
- Minimal Performance Impact — optimized for gameplay
